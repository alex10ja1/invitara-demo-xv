# Invitación de muestra · Invitara

Invitación digital de **muestra** (XV años) que usa Invitara para enseñar a sus clientes cómo se ve una invitación.

Todos los datos son inventados. La confirmación de asistencia está en **modo demo**: no envía nada.

Página de Invitara: https://alex10ja1.github.io/invitara/

Para cambiar los datos edita `data/configuracion.json`.
